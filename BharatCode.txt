What it is
----------
Showboard lets a coding agent answer questions about your data with boards
(charts, tables, headline numbers and notes) instead of paragraphs. The agent
writes read-only SQL over your Excel, CSV, SQLite or Postgres data; Showboard
runs it and draws the board in your browser, inside your own React app, or in
a terminal pane beside the agent. Every number comes from the data itself, and
every chart can show the query behind it.


How it works with BharatCode
----------------------------
Showboard is an MCP server. The BharatCode CLI (a fork of OpenCode) runs MCP
servers, so BharatCode's own models, Qwen 3.8 27B and DeepSeek V4.1 Flash on
the BharatCode model API, read your data and draw the boards.

In the folder with your data:

    npm install -g bharatcode
    bharatcode auth login
    npx -y showboard init "Sales 2026.xlsx" --agent bharatcode
    npx -y showboard doctor
    bharatcode .

Then ask: "What is in my data? Draw me a board of it." Boards appear at
http://localhost:4710, or in a terminal beside the agent with
"npx showboard pane".

`showboard init --agent bharatcode` writes Showboard into opencode.json, which
BharatCode reads. `showboard doctor` starts Showboard the way BharatCode will
and checks it answers.


Or ask without a coding agent
-----------------------------
With a BharatCode API key (bharatcode.ai/account), Showboard's board page gets
a question box. Showboard sends your question to Qwen 3.8 27B on the BharatCode
model API, with its own tools to read your tables and draw; the board appears
on the page, with a short answer above it.

    PowerShell:  $env:BHARATCODE_API_KEY = "<your key>"
    bash:        export BHARATCODE_API_KEY=<your key>
    npx -y showboard serve "Sales 2026.xlsx"

Open http://localhost:4710 and ask, e.g. "Which region sold the most this
year?" The key stays on your machine: only the local server uses it.


Needs
-----
Node.js 22.13 or later, and a BharatCode account with model access
(student, Lite or Pro).
